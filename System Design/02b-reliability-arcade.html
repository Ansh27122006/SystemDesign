Q1. In the Request Roulette game, if reliability is 90% and you fire 30 requests, roughly how many should fail?
0 — 90% is basically perfect
About 3 — 10% of 30 requests fail on average
Q2. In the cascade game, what does the circuit breaker actually do?
It repairs the failed service automatically
It stops calls from propagating further downstream once a failure is detected
Q3. With 3 replicas each at 80% reliability, why is the combined system reliability so much higher than 80%?
Because 80% × 3 = 240%, capped at 100%
Because the system only fails if ALL 3 independently fail at once — a much rarer event
Q4. Which of these best improves reliability rather than availability?
Adding more servers behind a load balancer to handle more traffic
Adding checksums and majority-vote reads to catch corrupted data
