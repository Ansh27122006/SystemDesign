L4 balancer (Transport layer)

L7 balancer (Application layer)

Reads the URL, headers and cookies. Servers are specialists, so it routes by content.

FeatureL4 (Transport)L7 (Application)
Data inspectedIP, portURL, headers, cookies, content
ProtocolsTCP / UDPHTTP / HTTPS, WebSocket
RoutingIP/port basedPath, host or content based
SpeedFaster, lower overheadSlightly slower, more processing
FlexibilityLimitedHigh (rewrites, redirects, rate limits)
Typical toolsAWS NLB, HAProxy (TCP)AWS ALB, Nginx, Traefik
L4 = fast + simple. Good for high traffic, gaming, streaming and low-latency needs.
L7 = smart + flexible. Good for APIs, microservices, A/B tests and canary deploys.
